# Asset attribution

**Nothing external is bundled yet.** Every sprite and prop in the garage is
drawn programmatically with Pixi `Graphics` in `web/garage/garage.js` — the
characters, the desks, the garage door, the neon sign. There is nothing here to
attribute because nothing was taken.

## Vendored library

| File | Source | License |
|---|---|---|
| `web/garage/vendor/pixi.min.js` | PixiJS v8.6.6, unmodified | MIT |

Vendored rather than loaded from a CDN so the garage works with no network —
which matters for a tool whose whole point is running unattended overnight.

## When real art lands

DESIGN.md §8 is the standing rule: **Kenney.nl CC0 only**, and every file's
origin recorded here — pack name, URL, license, and any modifications. CC0 does
not require the credit; the interview does.

Hard bans, restated from rules.md §2.2: no LimeZu assets, no Office-referencing
props or character likenesses, no CC-BY-NC anything.
